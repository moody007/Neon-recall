# Neon Recall v1.0.0

First portfolio release of **Neon Recall: Blackout Heist**.

## Included

- Solo ten-round memory run
- Two-player local multiplayer with selectable match length
- Multiple reveal/blackout frames per round
- Procedural mazes that remain locked during each round
- Changing poison layouts with guaranteed poison-free routes
- Health, shields, scoring, leaderboards, and competitive buff drafts
- Resizable 1280×720 presentation
- Headless automated tests

## Windows controls

- Solo / Player 1: WASD
- Player 2: arrow keys
- Space: end the reveal early
- Escape or MENU: pause and return to homepage

This is a portfolio game and an original project; it does not include Pac-Man artwork, branding, maze layouts, or other copyrighted assets.
