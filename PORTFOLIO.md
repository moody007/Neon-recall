# Portfolio material

## Repository description

Competitive C++20 memory-maze game where players study a neon labyrinth, then race through it in total blackout.

## Résumé one-liner

Built a procedural C++20/raylib memory-racing game featuring alternating reveal/blackout phases, constrained hazard generation, local multiplayer, competitive buff drafts, and automated simulation tests.

## Résumé bullets

- Engineered a deterministic C++20/raylib game-state system supporting solo play and configurable 2-player local matches with round scoring and final leaderboards.
- Implemented procedural maze carving and constrained poison placement that preserves a hazard-free route for both players across changing memory frames.
- Separated headless gameplay logic from rendering and added automated tests for maze connectivity, topology stability, multiplayer fairness, progression, and buff eligibility.
